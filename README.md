# 📊 Deal-ito 통합 실적 대시보드 (Deal-ito Performance Dashboard)

이 프로젝트는 엑셀 데이터를 기반으로 프로젝트(Deal)별 **매출 및 이익 실적**을 분석하고, 담당자 역할(고객/관리/소싱)에 따라 기여도를 자동 계산하여 시각화하는 Streamlit 웹 애플리케이션입니다.

## ✨ 주요 기능

* **엑셀 파일 업로드**: `.xlsx` 형식의 실적 데이터를 업로드하여 즉시 분석합니다.
* **유연한 기간 조회**: 사이드바 입력을 통해 원하는 월 범위(예: `1-3`, `1-12`)를 자유롭게 설정할 수 있습니다.
* **역할별 기여도 자동 계산**: 각 Deal에 대해 담당자의 역할에 따라 실적을 배분합니다.
* **고객 (Client)**: 40%
* **관리 (Management)**: 30%
* **소싱 (Sourcing)**: 30%


* **역할 필터링**: 전체 합산 실적뿐만 아니라, 특정 역할(예: 소싱 담당자 실적만)을 선택하여 조회할 수 있습니다.
* **시각화 대시보드**:
* 담당자별 실적 랭킹 테이블
* 실적 비중 파이 차트 (Plotly)
* 상세 내역 드릴다운



## 🛠 실적 반영 로직 (Business Logic)

이 대시보드는 **매출**과 **이익** 모두 동일한 비율로 담당자에게 실적을 인정합니다.

| 구분 | 컬럼명(엑셀) | 반영 비율 |
| --- | --- | --- |
| **고객 담당** | `Deal - 담당자_고객` | **40%** |
| **관리 담당** | `Deal - 담당자_관리` | **30%** |
| **소싱 담당** | `Deal - 담당자_소싱` | **30%** |

> **예시**: 매출이 1,000만원인 프로젝트의 경우
> * 고객 담당자에게 400만원 실적 인정
> * 관리 담당자에게 300만원 실적 인정
> * 소싱 담당자에게 300만원 실적 인정
>

## 📋 엑셀 파일 필수 양식 (Data Requirements)

정상적인 작동을 위해 업로드하는 엑셀 파일은 아래의 컬럼명을 반드시 포함해야 합니다.
*(**MM**은 `01`, `02` ... `12`와 같은 두 자리 월 형식입니다.)*

| 구분 | 필수 컬럼명 형식 | 설명 |
| --- | --- | --- |
| **기본 정보** | `Deal - 이름` | 프로젝트명 |
| **담당자** | `Deal - 담당자_고객` | 고객 담당자 이름 |
|  | `Deal - 담당자_관리` | 관리 담당자 이름 |
|  | `Deal - 담당자_소싱` | 소싱 담당자 이름 |
| **매출 데이터** | `Deal - @월별매출 (MM)` | 예: `Deal - @월별매출 (01)`, `Deal - @월별매출 (12)` |
| **이익 데이터** | `Deal - @월별이익 (MM)` | 예: `Deal - @월별이익 (01)`, `Deal - @월별이익 (12)` |

## 🚀 설치 및 실행 방법 (Getting Started)

### 1. 환경 설정

Python이 설치된 환경에서 필요한 라이브러리를 설치합니다.

```bash
pip install streamlit pandas plotly openpyxl

```

### 2. 애플리케이션 실행

터미널에서 아래 명령어를 실행합니다.

```bash
streamlit run app.py

```

### 3. 사용 방법

1. 브라우저가 열리면 사이드바에서 **조회할 월 범위**를 입력합니다 (기본값: 1-12).
2. **보고 싶은 역할**을 선택합니다 (전체/고객/관리/소싱).
3. 준비된 **엑셀 파일**을 업로드합니다.
4. **매출 분석** 탭과 **이익 분석** 탭을 오가며 데이터를 확인합니다.
